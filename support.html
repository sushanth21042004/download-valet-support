Let’s get things tidy.

Quick answers for setup, organization, purchases, and safe cleanup.

Getting started

  1. Open Download Valet and select Choose Downloads Folder.
  2. Choose your macOS Downloads folder and allow access.
  3. Wait briefly for completed files to settle, then review them under Ready to Organize.
  4. Select the files you want and choose Organize.

Why is a file not appearing?

Refresh the Smart Inbox and make sure the selected folder is correct. Incomplete browser downloads are intentionally ignored until complete. Hidden files, packages, and excluded files are also not offered for organization.

Where did my file go?

Open Activity to see its destination. You can use Undo while the organized file remains at that location. Name conflicts receive a numbered filename; an existing file is never overwritten.

How does duplicate detection work?

Download Valet compares eligible completed files locally using a cryptographic content hash. It only marks exact byte-for-byte matches.

How do I restore Pro?

Open Download Valet Pro and select Restore Purchase. Use the same Apple Account that made the original purchase. There is no subscription.
